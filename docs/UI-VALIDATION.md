# گزارش بررسی patch رابط کاربری

## مبنا

کدهای تغییرکرده با نسخه `0173c6fb8786f94114fd46043f62a32a06bcc1f1` از شاخه `main` تطبیق داده شده‌اند. محتوای فایل‌های موجود با hash فایل‌های مخزن بررسی شده است. patch به مسیرهای نسبی ریشه پروژه اعمال می‌شود.

## بررسی‌های انجام‌شده

- ۴۳۰ assertion موفق برای محاسبات، شامل همه ۲۰۸ ترکیب پکیج / توقف / ظرفیت.
- بررسی syntax و transpile فایل‌های TypeScript / TSX با TypeScript 5.8.3؛ بدون خطای syntax.
- تولید موفق utilityهای CSS با Tailwind 4.1.10.
- ۲۲ بررسی موفق در مرورگر Chromium با یک محیط آزمایشی مستقل React 18.2: چیدمان ۱۱۱۰ × ۶۱۸، موقعیت فرم در سمت راست، گزینه‌های فیلتر، انتخاب برند، غیرفعال / فعال کردن قلم، کلید Escape، فیلتر موتور ۷٫۵ / ۱۱، ورود اعداد فارسی، جستجو بدون تغییر جمع، پنجره قیمت مادر و مسیر فراخوانی چاپ.
- بررسی `git diff --check` و اعمال patch روی baseline تمیز.
- کاتالوگ و کد Rust مربوط به SQLite دست‌نخورده مانده‌اند.

## محدودیت‌های این بررسی

محیط آزمایشی مرورگر جای Build واقعی Next.js نیست. در آن، لایه `next/image` شبیه‌سازی شده و از تصویر ساده آزمایشی برای هیرو، برش لوگوی طرح و فونت سیستم استفاده شده است؛ این تصاویر جزو patch نیستند. کد نهایی به عکس‌ها و فونت‌های موجود در `public` خود مخزن اشاره می‌کند. بنابراین تطابق پیکسلی رنگ عکس و رندر فونت واقعی در این محیط تأیید نشده است.

دسترسی شبکه لازم برای نصب وابستگی‌های npm در محیط بررسی فراهم نبود؛ `npm install --offline` به دلیل نبودن بسته‌ها در cache متوقف شد. Build واقعی Next.js، typecheck کامل با typeهای وابستگی‌ها و Build نصب‌کننده ویندوز در این محیط تأیید نشده‌اند. اجرای این موارد روی سیستم توسعه لازم است:

```powershell
npm install
npm run test
npm run typecheck
npm run build
npm run desktop:dev
npm run desktop:build
```

بررسی چاپ شامل نمایش قالب چاپ و فراخوانی تابع چاپ بوده است، نه ساخت و تأیید فایل PDF در WebView2 ویندوز. چاپ چندصفحه‌ای و انتخاب Save as PDF باید روی نسخه ویندوز نیز آزمایش شوند.
