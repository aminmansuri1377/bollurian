## نصب تغییرات

ابتدا تغییرات شخصی پروژه را commit یا stash کنید. سپس از ریشه مخزن:

```powershell
git apply --check .\bollurian-desktop-tailwind.patch
git apply .\bollurian-desktop-tailwind.patch
npm install
npm run test
npm run typecheck
npm run build
npm run desktop:dev
```

برای پیش‌نمایش مرورگر از `npm run dev` و برای ساخت نصب‌کننده ویندوز از `npm run desktop:build` استفاده کنید. `npm install` ضروری است، چون Tailwind و افزونه PostCSS جدید هستند. فایل `package-lock.json` موجود را با همین دستور به‌روز و همراه پروژه commit کنید؛ پیش از این مرحله از `npm ci` استفاده نکنید.

## تصمیم‌های طراحی

عرض محتوای دسکتاپ ۱۱۱۰ پیکسل و ارتفاع هیرو ۶۱۸ پیکسل است. چیدمان هیرو عمداً `dir="ltr"` و متن هر ستون `dir="rtl"` دارد؛ بنابراین فرم همیشه در سمت راست قرار می‌گیرد. نسخه موبایل یا breakpoint واکنش‌گرا اضافه نشده است؛ در پنجره کوچک، صفحه اسکرول افقی خواهد داشت. حداقل عرض پنجره Tauri برابر ۱۱۷۰ پیکسل تنظیم شده است.

`app/page.css` حذف شده است. هیچ CSS Module، style JSX یا فایل استایل مخصوص کامپوننت وجود ندارد. تنها `globals.css` شامل import مربوط به Tailwind، توکن‌های رنگ و فونت و `@page` برای اندازه A4 است. استایل تمام عناصر و حالت‌های چاپ در `className` نوشته شده‌اند.

تعداد ردیف‌ها واقعی است و به ۱۱ ردیفِ نمونه طراحی محدود نشده است. ابزارهای مدیریتی در بخش بازشونده زیر گزارش قرار گرفته‌اند تا طراحی اصلی خلوت بماند. قیمت‌ها همچنان بر حسب تومان هستند. برای حذف یک قلم از محاسبات، منوی کنار نام آن را باز کنید.

## داده‌ها و محاسبات

کاتالوگ، قیمت‌های پایه، قواعد پکیج، محدودیت موتور ۷٫۵ / ۱۱ کیلووات و فرمول قبلی تغییر نکرده‌اند:

```typescript
Math.round(quantity * unitPrice * (1 + settings.rate / 100))
```

انتخاب نوع موتور هنوز همان رفتاری را دارد که در نسخه قبلی مخزن پیاده‌سازی شده بود؛ این patch هیچ قانون تجاری یا برندِ فاقد داده به برنامه اضافه نمی‌کند. موارد فاقد تعداد یا قیمت همچنان مشخص و مانع صدور PDF هستند. محدودیت‌های کاتالوگ قبلی با بازطراحی UI برطرف نشده‌اند.

جستجو فقط نمایش جدول را فیلتر می‌کند؛ برخلاف نسخه قبلی، باعث تغییر جمع کل یا حذف ناخواسته اقلام PDF نمی‌شود. مقدار صفر معتبر است. پاک‌کردن ورودی عددی، override را حذف می‌کند و مقدار مرجع را برمی‌گرداند؛ مقدار نامشخص به صفر تبدیل نمی‌شود.

ساختار دیتابیس، شناسه برنامه، نام commandهای Tauri و کلید ذخیره مرورگر تغییر نکرده‌اند. داده‌ها و نسخه‌های پشتیبان قبلی سازگار می‌مانند. ذخیره‌سازی‌های SQLite به ترتیب اجرا می‌شوند و خطای بارگذاری باعث بازنویسی اطلاعات قبلی نمی‌شود.

## چاپ و آزمون

قالب چاپ مستقل است: هیرو و دکمه‌ها چاپ نمی‌شوند، عنوان ستون‌ها در صفحات بعد تکرار می‌شود و متن طولانی کالا در سطر خودش می‌شکند. خروجی همچنان از پنجره Print / Save as PDF سیستم تهیه می‌شود؛ انتخاب نام و مسیر فایل در همان پنجره انجام می‌شود.

`npm test` فرمول‌ها، فیلترها، داده‌های ناقص، صفر، درصد تغییر، اعداد فارسی و سازگاری state قبلی را آزمایش می‌کند. `npm run typecheck` و `npm run build` باید با وابستگی‌های نصب‌شده پروژه اجرا شوند. برای تحویل نهایی، نسخه Release ویندوز و چاپ چندصفحه‌ای را در WebView2 سیستم مقصد نیز بررسی کنید.
